🪙 MoneyMint

Automated Student Financial Core — A premium, high-fidelity, single-file personal finance companion tailored for college students managing pocket money and irregular freelancing gigs.

🌟 Overview

MoneyMint is a modern, responsive personal finance core engineered specifically to eliminate tracking friction for students and micro-freelancers. Unlike heavy, ad-laden finance apps, MoneyMint is built as a single, self-contained HTML engine.

It functions 100% client-side, using secure browser storage (localStorage) to guarantee absolute privacy—your financial data never leaves your device.

🚀 Key Features

⚡ Real-Time KPI Dashboard: Monitor active liquid balance, monthly inflow/outflow, and a projected end-of-month balance computed dynamically using daily burn velocity.

📊 Algorithmic Financial Health Score: A proprietary indicator scoring your financial habits out of 100 points, tracking savings metrics, budget adherence, and cash flow stability.

💾 Local Storage Persistence: Full offline reliability. Your transactions ledger, budget limits, custom categories, and milestones are secured locally and automatically.

📈 Native SVG Vector Charts: Seamless, responsive charts (Ring/Donut budget share charts, comparative cashflow bars, and a day-by-day continuous linear spending vector) drawn dynamically on-the-fly without bloated third-party libraries.

🛠️ Control Terminal: Customize your baseline cash reserves, add custom income streams (e.g. Tutoring, Design Gigs), define targeted budget thresholds, or wipe/reset data with one click.

🌓 Unified Dark/Light Modes: Modern minimalist design that matches your system system preferences instantly.

📦 Tech Stack

UI Framework: Tailwind CSS v3 (Loaded via CDN)

Core Engine: Pure ES6+ JavaScript

Icons: Inline SVG vectors (No external font files required)

Data Tier: Web Storage API (localStorage)

🛠️ Getting Started & Local Installation

Because MoneyMint is self-contained in a single file, setup takes less than 30 seconds.

Prerequisites

A modern web browser (Chrome, Safari, Firefox, Edge, or Brave).

Running Locally

Clone this repository or download the source code:

git clone [https://github.com/yourusername/moneymint.git](https://github.com/yourusername/moneymint.git)


Navigate to the project directory and double-click index.html to run it instantly. No local web servers or Node dependencies required.
